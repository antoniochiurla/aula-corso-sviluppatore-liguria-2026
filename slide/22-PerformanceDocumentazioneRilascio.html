Monitoraggio delle Performance

  • Metriche Chiave:
    • Tempi di risposta (Latency): Quanto ci mette TaMaSy a caricare una pagina?
    • Carico (Throughput): Quante richieste al secondo può gestire prima di rallentare?
    • Error Rate: Qual è la percentuale di errori (es. 500 Server Error) rispetto alle richieste totali?
  • TaMaSy: Il check-up finale: TaMaSy è abbastanza veloce per essere lanciato sul mercato?

Analisi richieste con Django Toolbar

  • Django Debug Toolbar
    • pip install django-debug-toolbar
    • aggiungere 'debug_toolbar' a INSTALLED_APPS
    • 'debug_toolbar.middleware.DebugToolbarMiddleware' in MIDDLEWARE
    • DEBUG_TOOLBAR_CONFIG = {

"SHOW_TOOLBAR_CALLBACK": show_toolbar,
}

Analisi Log e Metriche Operative

  • Interpretazione dei Log
    • Non solo cercare l'errore, ma capire il comportamento
    • Esempio: "Molti utenti cliccano su X ma poi tornano indietro: forse X non funziona bene?"
  • Analisi dei picchi
    • Identificare nei log i momenti di stress del sistema
  • Metafora TaMaSy
    • Leggere i log operativi è come guardare i dati storici per capire perché martedì scorso era triste
    • Analisi post-mortem

La Documentazione di Rilascio

  • Check-list di Deployment
    • Una lista di azioni da fare per mettere online l'app
    • Esempi
      • python manage.py migrate
      • caricare le immagini
      • impostare le variabili d'ambiente
  • Report di Test
    • Un riassunto finale che dice: "Abbiamo eseguito 50 test, 48 sono passati, 2 bug minori noti"
  • Note di Rilascio (Release Notes)
    • Cosa c'è di nuovo in questa versione?
    • Esempio: "TaMaSy v1.0: Aggiunto supporto per priorità, corretto bug nelle date"

Tracciabilità e Post-Deployment

  • Tracciabilità

    • Esempio: "Il commit X su GitHub risolve il Bug Y segnalato nel report"
