Analisi dei Requisiti e Scenari di Test

  • Requisiti Funzionali
    • L'utente deve poter creare un task
  • Requisiti Non Funzionali
    • Il salvataggio deve impiegare meno di 1 secondo
  • Scenario di Test
    • Una descrizione ad alto livello di una situazione d'uso
    • TaMaSy
      • Scenario
        • Un utente dimentica il titolo e prova a salvare
        • Cosa deve succedere?

Il Piano di Test (Test Plan)

  • È il documento guida
  • Deve contenere:
    • Obiettivi
      • Cosa vogliamo ottenere? (es. Zero bug critici)
    • Scope (Perimetro)
      • Cosa testiamo?
        • Esempio: La Dashboard
      • Cosa NON testiamo?
        • Esempio: Il recupero password, se non è ancora pronto
    • Criteri di Accettazione
      • Qual è la condizione per dire "TaMaSy può andare online"?
        • Esempio: Il 100% dei test critici è superato

Casi di Test (Test Cases) e Dati di Test

  • Test Case
    • Il dettaglio atomico
    • Ogni caso ha
      • ID
      • Descrizione
      • Pre-condizioni
      • Passaggi
      • Risultato Atteso
  • Test Data: I dati necessari per il test.
    • Esempio: Per testare un filtro per data, ho bisogno di un database "sporco" con task nel passato, nel presente e nel futuro

Ambiente di Test (Test Environment)

  • Differenza tra:
    • Sviluppo (Dev)
      • Il PC del programmatore (dove tutto funziona sempre)
    • Test/Staging
      • Una copia molto simile al sistema di produzione dove si fanno i test finali
    • Produzione (Prod)
      • Dove ci sono gli utenti veri (NON si testa mai qui!)
  • TaMaSy Slide
    • Creeremo un database di prova separato per non inquinare i dati reali

Strategie: TDD e BDD

  • TDD (Test-Driven Development)
    • Scrivi il test -> Il test fallisce -> Scrivi il codice -> Il test passa
  • BDD (Behavior-Driven Development)
    • Scrivere i test in linguaggio umano
    • Esempio
      • DATO che sono sulla pagina principale, QUANDO clicco 'Nuovo', ALLORA devo vedere un form

Laboratorio Tecnico

  • Analisi dei Piani
    • Revisione insieme dei piani scritti
    • Cosa manca
    • Cosa è troppo vago?
  • Setup Ambiente
    • Configurazione di un ambiente di test locale (es. un database SQLite separato per i test in Django)
